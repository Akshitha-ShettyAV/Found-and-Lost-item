# Member 2 – Report Lost Item Module

## Project: Campus Lost and Found Portal

This module allows students to report items they have lost on campus.

### Features
- Report a lost item.
- Enter item name and description.
- Provide the lost item's location and date.
- Upload an item image.
- Store lost-item details in a database.

### Technologies Used
- Python
- Flask
- HTML and CSS
- SQLite

### Project Files
- `demo_app.py` – Main Flask application.
- `lost_items/` – Lost-item module files.
- `tests/` – Test files.
- `requirements.txt` – Python dependencies.
